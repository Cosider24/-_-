# Анализ продаж Superstore

Этот проект представляет собой анализ датасета **Superstore Sales** с использованием Python и Google Colab. Датасет содержит информацию о продажах, клиентах, товарах и географическом положении заказов в США.

## Цель анализа
Основная цель — провести первичный разведочный анализ данных (EDA) для выявления ключевых бизнес-показателей и закономерностей в продажах.

## Основные шаги и выводы
1.  **Загрузка и первичный осмотр данных:**
    *   Загружены данные из файла `Superstore_Sales_train.csv`.
    *   Удален бесполезный столбец `Row ID`.
    *   Выявлены пропуски в столбце `Postal Code` (11 пустых значений).

2.  **Предобработка данных:**
    *   Столбцы `Order Date` и `Ship Date` преобразованы из строкового формата в формат `datetime` для корректной работы с датами.

3.  **Анализ выручки по категориям:**
    *   Построен столбчатый график, показывающий суммарную выручку по трем категориям товаров: **Furniture**, **Office Supplies** и **Technology**.
    *   **Вывод:** Категория **Technology** приносит наибольшую выручку (более 827 тыс. у.е.).

4.  **Анализ динамики продаж:**
    *   Сгруппированы данные по годам, чтобы увидеть тренд изменения выручки.
    *   Построен линейный график, демонстрирующий рост или падение продаж по годам.
    *   **Вывод:** Наблюдается устойчивый рост продаж с 2015 по 2018 год. Пик выручки пришелся на **2018 год** (более 722 тыс. у.е.).

## Используемые библиотеки
*   `pandas` — для обработки и анализа данных.
*   `matplotlib.pyplot` — для визуализации данных (построение графиков).
